# 🌱 Sprout Ville

A **2D farming simulation prototype** built in **Unity**, inspired by classic life-sim and farming games.  
The project focuses on **core gameplay systems**, clean architecture, and extensibility rather than content scale.

---

## 🎮 Features

### 🌾 Farming System

- Tile-based farm grid
- Soil ploughing, watering, planting, and harvesting
- Multi-stage crop growth system
- Multiple crop types with distinct growth stages

### 🧑 Player Systems

- Top-down 2D movement
- Tool-based interaction system (hoe, watering can, seeds, harvest)
- Mouse-based targeting with grid snapping
- Animated tool usage

### 🕒 Time & Day Cycle

- In-game clock with configurable day length
- Day/night lighting transitions
- Sleep system to advance days

### 🧺 Inventory & Economy

- Seed and crop inventory management
- Buy/sell system via shop UI
- Currency tracking and updates
- UI-driven inventory and shop panels

### 🗺️ World & Scene Flow

- Indoor and outdoor scenes
- Area-based scene transitions
- Fade-in / fade-out scene loading
- Persistent player across scenes

### 🤖 NPC & Tutorial System

- Guided tutorial flow for new players
- NPC dialogue system with typing effect
- NPC schedules (day/night behavior)
- Tutorial progression tracking

---

## 🛠️ Tech Stack

- **Engine:** Unity 6 (2D)
- **Language:** C#
- **Input System:** Unity Input System
- **Rendering:** 2D Tilemaps + Lighting
- **Architecture:** Modular controllers and managers
- **Version Control:** Git + GitHub

---

## 🎯 Design Goals

- Clean, readable, and maintainable code
- Clear separation between gameplay logic and visuals
- Systems designed to be easily expandable
- Focus on gameplay feel and iteration speed
